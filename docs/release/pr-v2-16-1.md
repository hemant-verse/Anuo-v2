# PR-V2-16.1 — Integration Test Environment Reliability

## Purpose

Fix local Node test execution issues discovered during PR-V2-16 verification.

## Changes

- Integration/E2E database helper now loads `.env.local` and `.env` for Node-based test scripts.
- Placeholder MongoDB/secret values are rejected rather than treated as configured.
- MongoDB connection failures now fail fast with a diagnostic error instead of Mongoose buffering timeouts.
- Database cleanup refuses to execute while disconnected.
- Relative ESM imports in authentication/product services now include `.js` extensions so the Node test loader resolves them correctly.

## Required local setup

Use a dedicated non-production MongoDB database and set a real connection string in `.env.local` or the shell.

Example local MongoDB URI:

`mongodb://127.0.0.1:27017/auno_v2_test`

Do not commit credentials or production connection strings.

## Verification

- JavaScript syntax checks pass for modified files.
- Integration/E2E execution must be rerun by the developer with a reachable MongoDB instance.
