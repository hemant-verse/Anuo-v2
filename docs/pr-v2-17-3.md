# PR-V2-17.3 — Deterministic Browser E2E Runner

## Purpose

Make the Playwright browser runner fail fast and expose server startup diagnostics instead of silently waiting while the Next.js server is being started.

## Changes

- Playwright `webServer` keeps automatic server startup/reuse.
- Next.js stdout/stderr are inherited by the terminal so startup errors are visible.
- Server readiness timeout is reduced to 60 seconds.
- Browser tests and application code are unchanged by this PR.

## Verification

Run:

```bash
pnpm e2e:browser
```

Expected flow:

```text
E2E fixtures created: .../.e2e-state.json
<Next.js startup output>
Running 3 tests using 1 worker
...
```

If the server cannot start, the command must terminate within the configured readiness timeout and print the underlying server error.

Browser E2E is VERIFIED only after the three browser tests execute successfully on the real local environment.
