# PR-V2-17.2 — Browser E2E Infrastructure

## Purpose

Add a real Playwright browser layer for the V2 critical journeys without replacing the existing HTTP E2E suite.

## Coverage

- Buyer: login → browse/search → favorite → favorites
- Seller/Admin: create listing → pending → approve → audit
- Security UI: unauthenticated protected-route redirect

API setup is used only to establish deterministic data for the buyer UI test. The seller/admin journey exercises the listing form, image upload, moderation UI, and audit UI through a real browser.

## Local setup

After extracting this PR:

```bash
pnpm install
pnpm exec playwright install chromium
```

Then ensure the normal Auno E2E environment is configured (`.env.local`, MongoDB, Upstash, ImageKit as required by the application).

Run:

```bash
pnpm e2e:browser
```

For interactive debugging:

```bash
pnpm e2e:browser:ui
```

## Verification rule

Do not mark browser E2E complete from static inspection. It becomes VERIFIED only after the browser suite executes successfully against the real Auno server.
